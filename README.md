# ❤️ Cardiac Disease Prediction Using Machine Learning

## 📌 Overview

Cardiac Disease Prediction is a machine learning project that predicts the likelihood of heart disease based on patient health parameters. It provides a simple web interface where users can enter patient details and receive a prediction from a trained machine learning model.

The application is developed using Python and Streamlit, with Scikit-learn for machine learning.

**Note:** This project is intended for educational purposes only and is not a substitute for professional medical advice or diagnosis.

## 🎯 Objectives

- Analyze patient health data to predict heart disease.
- Preprocess and transform data for machine learning.
- Train and compare multiple classification algorithms.
- Select a model based on evaluation metrics, including recall for the positive class.
- Build an interactive web application for making predictions.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Frontend / Web UI:** Streamlit
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **Data Transformation:** SciPy
- **Development Tools:** VS Code, Jupyter Notebook
- **Version Control:** Git and GitHub

## 🤖 Machine Learning Models

The project compares the following classification algorithms:

- Decision Tree Classifier
- Random Forest Classifier
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)

The models are evaluated using classification metrics, with recall for class 1 used as an important selection criterion.

## ✨ Features

- Interactive patient input form.
- User-friendly dropdowns for categorical features.
- Data preprocessing and feature encoding.
- Saved trained model for predictions.
- Prediction results displayed directly in the web application.
- Simple and beginner-friendly interface built with Streamlit.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Cardiac-Disease-Prediction.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Navigate to the project directory

```bash
cd Cardiac-Disease-Prediction
```

### 3. Install the required libraries

```bash
python -m pip install -r requirements.txt
```

### 4. Run the Streamlit application

Run using - ` py -m streamlit run app.py`

On Windows, you can also use:

```bash
py -m streamlit run app.py
```

The application will open in your browser, usually at:

`http://localhost:8501`

## 🩺 How to Use

1. Start the Streamlit application.
2. Enter the patient's health details in the form.
3. Select the appropriate categorical values.
4. Click the **Predict** button.
5. View the prediction generated by the trained model.

## 📊 Model Evaluation

The project compares multiple classification models and uses evaluation metrics to assess their performance. Recall for class 1 is considered when selecting the model because identifying positive cases is an important objective for this project.

Actual model performance depends on the dataset, preprocessing, and evaluation results.
